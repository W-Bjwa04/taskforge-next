This is a full-stack todo application built with Next.js, offering user authentication, a REST API, and a user-friendly interface. Users can register, log in, create, update, and delete todo items.

## Description

The Next.js Todo App is a modern, full-stack web application that allows users to manage their todo lists efficiently. It leverages the power of Next.js, along with a robust REST API and user authentication, to provide a seamless and secure user experience. The application is designed to be intuitive and responsive, making it easy for users to keep track of their tasks.

## Features

*   **User Authentication:** Secure user registration and login functionalities are implemented using JWT (JSON Web Tokens).
*   **Todo Management:** Users can create, read, update, and delete todo items with ease.
*   **REST API:** A well-structured REST API is provided to manage todo data, offering endpoints for creating, reading, updating, and deleting todos.
*   **Next.js App Router:** The application is built using the latest Next.js App Router, ensuring improved performance, efficient routing, and server components.
*   **Database:** MongoDB is used as the database, providing a flexible and scalable solution for storing user data and todo items.
* **Completed Todos** : Mark completed your todos, for better management.
* **Settings**: Manage the profile

## Technologies Used

*   **Next.js:** A React framework for building full-stack web applications.
*   **React:** A JavaScript library for building user interfaces.
*   **MongoDB:** A NoSQL database used for data persistence.
*   **Node.js:** A JavaScript runtime environment.
*   **TypeScript:** A statically typed superset of JavaScript.
*   **JWT (JSON Web Tokens):** For secure user authentication.
